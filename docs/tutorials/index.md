# Tutorials

Hands-on walkthroughs of the four dimensions BLEECAM evaluates for every
supply-chain configuration. Each tutorial runs a real case and shows how that
dimension is computed, optimized, and interpreted inside BLEECAM — not LCA,
TEA, or S-LCA in the abstract, but the way BLEECAM actually uses them.

We are building these one at a time, starting with LCA:

- [LCA guide for Critical Minerals and Materials](lca.md) — the four ISO 14040/14044
  phases (system boundary, inventory, impact assessment, scenario analysis) in the
  BLEECAM context, plus pairing the LiAISON LCA engine. *(available)*
- Techno-economic analysis (TEA) — the cost of the supply-chain configuration
  and its breakdown. *(planned)*
- Life-cycle costing (LCC) — cost across the full life cycle. *(planned)*
- Social LCA (S-LCA) — social-risk indicators. *(planned)*
