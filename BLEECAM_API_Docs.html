config.py

bleecam/config.py

Global model configuration — process lists, location lists, material lists, active process-location mappings, and all scalar penalty constants. Edit here to add new processes, locations, or change penalty rates.

bleecam/REE.py

Main model entry point. Loads data, applies scenario overrides, builds the Pyomo ConcreteModel, invokes IPOPT, post-processes and scales outputs, writes results to CSV and HTML, and spawns the dashboard.

def total_cost_rule(model)

Return the total cost objective expression for the Pyomo model. Sums processing cost, domestic transport cost, shipping cost, and tariff cost over all flowQ variables, plus stock holding costs, the unused-oxide penalty (PENALTY_UNUSED_OXIDE_COST × total_unused_oxides), and the demand slack penalty (slack_penalty_cost × Σ(slack_pos + slack_neg)).

Parameters

Returns
Pyomo expression — passed directly to Objective(rule=..., sense=minimize). Note: objective value = real cost / FLOW_SCALE during solve; multiply by FLOW_SCALE for display.
def total_emissions_rule(model)

Return the total GWP emissions objective expression. Weights each flowQ variable by its emission factor from ef_factor, adds the unused-oxide GWP penalty and demand slack penalty. Use by setting ACTIVE_OBJECTIVE = 'gwp'.

Parameters

def total_child_labor_rule(model)

Return the total child-labor Social LCA objective expression. Weights each flowQ variable by its child-labor impact factor from slca_factors['child_labor']. Four additional SLCA categories (forced labor, fatal injury, non-fatal injury, unemployment) are loaded but not currently used as primary objectives. Use by setting ACTIVE_OBJECTIVE = 'slca'.

def demand_fulfillment_constraints(model, high_perf_magnet_required)

Add soft demand constraints using slack variables. Total hp_magnet inflow to the use phase must equal demand per period, but slack variables demand_slack_pos (unmet demand) and demand_slack_neg (over-supply) allow infeasibility to be detected and penalized rather than hard-infeasible. Slack is penalized by slack_penalty_cost in the objective.

def weibull_historic_retirement(model, data_dir='./data')

Compute historic in-use magnet retirements per time period using a Weibull lifetime distribution fitted to fleet deployment data. Loads historic_installs.xlsx, reads the original column (actual kg install data), and applies a Weibull CDF with shape k=1.5 and mean life 31.1 years to calculate what fraction of each installation cohort retires in each model period.

Important: Must read the original column, not installs (which is all zeros, a legacy artifact). The installs2 column (= original/1000) also works but original is authoritative.

Parameters

Returns
dict[int, float] — time period to historic retirement quantity in FLOW_SCALE units (tonnes). Typical values: ~34–38 tonnes per period with current install base.
def use_phase_stock_constraints(model, retirement_rate=0.02, initial_use_stock=0.0, historic_retirements_by_t=None)

Add stock balance constraints for the in-use magnet fleet. Outflows from the use phase (to EOL routes) are bounded by the sum of the simple rate-based retirement and Weibull-computed historic retirements. Stock is updated each period: stock[t] = stock[t−1] + inflow − rate_retirement.

def _eol_lagged_constraints(model, recovery_rate, current_process, destination_process, input_output_map)

Generic lagged mass-balance constraint for an end-of-life recycling route. Links t−1 retirement outflows from the use phase to t outputs from the recycling process via recovery rates. This one-period lag represents the time required to process retired magnets. The five named EOL constraint functions below are wrappers that call this with route-specific arguments.

def add_stock_constraints(model, initial_stock, max_stock_capacity)

Add inventory balance constraints for all stock materials: stock[t] = stock[t−1] + flow_to_stock − flow_from_stock. Also adds upper-bound capacity constraints and a complementarity constraint (flow_to_stock × flow_from_stock = 0) to prevent simultaneous in/out flows.

def add_unused_oxides_tracking(model, locations)

Add Pyomo Expressions tracking co-product oxide misrouting. Defines model.unused_DyOx_to_MSE (DyOx routed to molten-salt electrolysis, which expects NdOx), model.unused_NdOx_to_MR (NdOx routed to metallothermic reduction, which expects DyOx), and their sum model.total_unused_oxides. The penalty on this expression discourages the solver from misrouting co-product oxides.
