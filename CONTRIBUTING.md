# Contributing to BLEECAM™

Thank you for your interest in contributing to BLEECAM. Contributions — bug reports, fixes, new case studies, and documentation — are welcome.

Contributing a **new critical-mineral case study**? Start with [ADDING_A_MATERIAL.md](ADDING_A_MATERIAL.md), which walks through defining a case from data and configuration.

## How to contribute

1. Fork the repository and create a feature branch off `main`.
2. Make your change, with tests where applicable (`pytest`).
3. Open a pull request against `main` describing what changed and why.

## Contributor License Agreement (CLA)

For contributions to BLEECAM, we ask contributors to also submit an explicit Contributor License Agreement, which provides a clear copyright and patent license to the Alliance for Energy Innovation, LLC and the U.S. Department of Energy, consistent with DOE software practice.

To submit it:

1. Open your pull request against `main`.
2. **Concurrently**, and **before your PR is merged**, email the text of [`CLA.txt`](CLA.txt) — from the email address associated with your contribution, and including your full name, your GitHub username, and a link to your pull request — to:

   **Sherif Khalifa — Sherif.Khalifa@nlr.gov**

3. The maintainer will confirm receipt prior to merging.

A single CLA covers your future contributions to BLEECAM; you do not need to resend it for each pull request.
